# Launch the Delta-period COVID-19 explorer app

Opens a Shiny app that helps public health students compare new cases
and vaccination coverage across countries during the Delta period (June
to November 2021).

## Usage

``` r
launch_app()
```

## Value

Called for its side effect of launching the app. Returns nothing.

## Examples

``` r
if (interactive()) {
  launch_app()
}
```
